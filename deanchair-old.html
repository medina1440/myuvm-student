Advising Reports

  • Academic Alerts
    Comprehensive list of all students in your department (chairs) or unit (deans) who have been issued an academic alert. Students will appear once for each course in which they have received an alert.

  • Advisor Notes (Summarized by Student)
    View advisor notes submitted for an individual student.
  • Advisor Notes (Summarized by Advisor)
    View data regarding the number of notes submitted by advisors in your unit.
  • Registered Students Sending Transcripts
    Customizable report returns a list of students who have requested transcripts.
  • Students by Major, Minor, Concentration
    Customizable report returns a list of students for selected academic program(s).
  • Students with < 12 Credits
    List of students not registered (or registered as less than full time) for the next major term.
  • New Incoming/Readmitted Students with < than 12 Credits
    Reports new incoming/readmitted students registered for less than 12 hours, including 0 credits, for the selected term.
  • View Pending Withdrawal Requests

Course Reports

  • Basic Course Information Report
    This report provides a list of all active/inactive courses. Selection choices include college, department, and subject.
  • Course Renumbering 3 to 4 Digit Report
    This report displays courses with their 3 and 4 digit numbers. The report is based on the original spreadsheet submissions. Course changes made after the spreadsheets were processed are not reflected.
  • Course Renumbering Widget
    This tool will give you the new 4-digit number when you enter an old 3-digit number. The widget is based on the original spreadsheet submissions. Course changes made after the spreadsheets were processed are not reflected.
  • Expanded Section Description Report
    This report can be used to see how many active sections for a desired term have or are missing an Expanded Section Description.
  • Instructions for Reviewing Special Topics Courses
    This document contains instructions on how to identify Special Topics sections in Course Reports.
  • Distribution/Balance (GP)
    This report can be used to show how sections desiring only general purpose space are distributed across the days and times of the standard meeting patterns. Prime time is considered 9:40am-2:00pm MWF or 10:05am-4:05pm TR.
  • Distribution/Balance (ALL)
    This report can be used to show how all sections are distributed across the days and times of the standard meeting patterns. Prime time is considered 9:40am-2:00pm MWF or 10:05am-4:05pm TR.
  • Balance for Meeting Analysis
    This report can be used to view the balance of courses by meeting pattern for a specific term.
  • Course Reason Analysis
    This report can be used to view demand with known capacity by course for a specific term.
  • Course Report Menu
    This report can be used to view current enrollment by course for a specific term.
  • Enrollment Summary
    This report can be used to compare enrollment by course across multiple terms.
  • Prerequisite Report
    This report can be used to view prerequisites for a particular subject in a specific term.
